# World packs

A `.ltpack` carries a reusable world to another install or account without taking anyone's play history. Choose **Export pack…** in a world editor; choose **Import pack…** from the Worlds list.

## Export

The pack includes world settings and rules, lore, selected cast templates, and selected backgrounds, sprites, and music. The export dialog shows optional private items such as GM notes, play-confirmed canon, sheets, player cards, and VRM models. Review each choice and the file size. Credit art and music authors and state a license when you share a pack. Stories, messages, memories, recaps, accounts, API keys, and preferences never go in the pack.

## Import

Import previews the world, cast, media size, credits, omitted data, dropped references, and name collisions before writing anything. A conflict can be imported as a renamed copy, skipped in favor of yours, or replaced with a separate confirmation. A new import belongs privately to the importing account until shared. The importer checks paths, sizes, hashes, and media types and writes records transactionally.

The [repository format and safety guide](https://github.com/guswadsworth12/Lost-Tale-Engine/blob/master/docs/WORLD_PACKS.md) documents the archive layout and limits. Back up your own install before a large import; see [Backup, Restore and Privacy](https://github.com/guswadsworth12/Lost-Tale-Engine/wiki/Backup-Restore-and-Privacy).
