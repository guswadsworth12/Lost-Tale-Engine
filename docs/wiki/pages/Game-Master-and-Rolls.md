# Game Master and rolls

The Game Master (GM) judges declared actions, paces a scene, narrates public consequences, and chooses which non-player character acts next. It does not speak for the player character. The world's **Story Rules** decide whether a check is **guided** or **mechanical**.

## Guided and mechanical resolution

Guided mode gives the GM a ruleset and rank context for narrative judgment. It does **not** record a die result or promise a mechanical success tier. Mechanical mode uses a move, a character sheet value or entered modifier, and a server roll. The result is stored before the GM narrates it. The stored dice, target, modifier, and outcome remain authoritative even if generated prose disagrees.

1. Set the ruleset and mode in **Worlds → Story Rules**.
2. Give the player character a sheet for this world in **Cast → Sheet**. If there is no sheet at all, enter a modifier when prompted; if the character has sheets for other worlds, add one for this world.
3. In the scene, choose **Make a move / roll**, inspect the move and target, and submit it.
4. Read the recorded outcome and the GM narration. A miss must remain a miss. A success may still invite questions, choices, or follow-up action; it does not end your agency.

The GM can ask for a roll when no recorded check exists, but cannot retroactively declare a mechanical result. A rank ladder helps decide what is routine or beyond reach; it does not replace the server roll. If a narration contradicts the roll, inspect the recorded check and correct or regenerate the narration.

Moves can apply tracked resource, condition, clock, and item changes. The server stores those with the roll so a repeated submission cannot apply them twice. See [Story State and Continuity](https://github.com/guswadsworth12/Lost-Tale-Engine/wiki/Story-State-and-Continuity) and [Ruleset Builder](https://github.com/guswadsworth12/Lost-Tale-Engine/wiki/Ruleset-Builder).
