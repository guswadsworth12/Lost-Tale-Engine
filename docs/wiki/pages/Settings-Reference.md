# Settings reference

Open **Settings** from the main menu. On phones, choose a section from the selector at the top. Settings provide defaults; a world's modules and a story's own choices can override them.

| Section | What to change |
| --- | --- |
| Get set up | First-run connection and setup guidance |
| Models and services | Text endpoint, model, and optional service connections |
| Appearance | Theme, layout, Visual Novel input and text speed, sound, reduced motion, custom CSS |
| Generation | Context, memory, prompt behavior, choices, writing style, sampler |
| Voice | Speech provider, voice playback, auto voice |
| Images | Image provider, prompt drafting, inclusion defaults |
| Data | Full backup download and restore |
| Account | Sign-in and account controls |

To diagnose poor replies, first check the active text model in **Models and services**, then inspect the scene's context and world rules. To diagnose a missing image or voice, test that service independently; text generation working does not prove optional media providers are connected. To reduce motion on a slow device, use **Appearance → Reduced motion** and a simpler stage layout.

See [Models and Services](https://github.com/guswadsworth12/Lost-Tale-Engine/wiki/Models-and-Services) and [Backup, Restore and Privacy](https://github.com/guswadsworth12/Lost-Tale-Engine/wiki/Backup-Restore-and-Privacy).
