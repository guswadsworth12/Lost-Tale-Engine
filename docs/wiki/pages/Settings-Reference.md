# Settings reference

Open **Settings** from the main menu. On phones, choose a section from the selector at the top. Settings provide defaults; a world's modules and a story's own choices can override them.

| Section | What to change |
| --- | --- |
| Get set up | The setup checklist: Text model, Voice, Images, First story. Each step ticks itself once it's done; **Run the whole setup again** reopens the wizard |
| Models and services | Services and keys, and which model does each job |
| Appearance | Theme, layout, Visual Novel input and text speed, sound, reduced motion, custom CSS |
| Generation | Context, memory, prompt behavior, choices, writing style, sampler, reasoning token reserve |
| Voice | Voices, playback, auto voice |
| Images | Image prompt drafting and who is included by default |
| Data | Full backup download and restore (owners), and the guided tour |
| Account | Your sign-in, sign-out, and password |
| Admin | Owners only: users, what happens when you remove someone, and what removed accounts left behind |

![Settings → Get set up with Text model, Voice, and First story ticked and Images still to set up](https://raw.githubusercontent.com/guswadsworth12/Lost-Tale-Engine/master/screenshots/wiki-get-set-up.jpg)

The account menu in the top-right corner is the quick way to **Change password**, **Sign out**, or open **Account** and **Admin**; see [Accounts and Sharing](https://github.com/guswadsworth12/Lost-Tale-Engine/wiki/Accounts-and-Sharing).

To diagnose poor replies, first check the active text model in **Models and services**, then inspect the scene's context and world rules. To diagnose a missing image or voice, test that service on its own; text generation working does not prove optional media services are connected. To reduce motion on a slow device, use **Appearance → Reduced motion** and a simpler stage layout.

See [Models and Services](https://github.com/guswadsworth12/Lost-Tale-Engine/wiki/Models-and-Services) and [Backup, Restore and Privacy](https://github.com/guswadsworth12/Lost-Tale-Engine/wiki/Backup-Restore-and-Privacy).
